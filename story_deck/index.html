The key change

We stopped writing every rule.

Instead, we gave the system examples and a way to measure error.

Traditional softwareif temperature < 18° → turn heat on

Presenter notes

Purpose
Show what “learning from examples” means before introducing linear algebra or neural-network vocabulary.
Say
“Each row is a past situation. The first four columns are inputs; the last is the target. The model starts with imperfect weights, makes a prediction, measures the error, and adjusts the weights.”
Walk through
Encode occupied soon as 1. For the new case, the current weights predict 65% heating. The observed requirement is 70%, so the error is five percentage points.
Connect to deep learning
One unit combines weighted inputs. A neural network connects many units and adds nonlinear transformations. “Deep” means that representations pass through many learned layers.
Important nuance
Four rows cannot train a useful building system. These are course-authored teaching data; a real model would need many observations, careful validation, and monitoring when conditions change.

A practical definition

AI infers an output from an input.

It might predict, generate, recommend, decide—or choose an action.

leaf photo→disease label
long paper→summary
experiment history→next candidate
goal + tools→sequence of actions

The label “AI” does not tell us whether a system is conscious, reliable, fair, or autonomous.

RAG · background

RAG gives the model an open book at answer time.

What the model already hasBroad patterns compressed into trained weights.
+
What retrieval adds nowRelevant passages selected for this question.

RAG = retrieval-augmented generation. It changes the context—not the model’s weights.

By the end: explain each stage · inspect one retrieval trace · diagnose one failure.

Presenter notes

Purpose
Define RAG before discussing its motivation or architecture, and distinguish it from training or fine-tuning.
Time
One minute. Treat this as the learning contract, not a history lecture.
Say
“The model brings broad patterns learned during training. The retrieval system brings a small set of passages selected for this question. Generation then happens with both.”
Background
The term retrieval-augmented generation was introduced in 2020 for systems that combine external retrieval with neural text generation. The source collection remains outside the model and can change without retraining it.
Clarify
RAG does not teach the model the documents permanently. It constructs a temporary evidence packet at answer time.

Step 2 · Vectorization

Turn every chunk—and the question—into comparable numbers.

This labTF–IDF vectors

Words receive more weight when they are frequent in one chunk but uncommon across the corpus. Simple, lexical, inspectable.

Many larger systemsEmbedding vectors

A learned model places semantically related passages near one another—even when they use different words.

Same principle: represent the question and chunks in the same vector space so closeness can be measured.

Presenter notes

Purpose

Clarify
TF-IDF depends strongly on shared vocabulary. Embeddings can capture paraphrase and semantic similarity, but they do not eliminate retrieval errors.

Step 6 · Verification

A citation is useful only if the evidence chain survives inspection.

Claim→Citation→Retrieved chunk→Original file
01Resolve

02Match

Does the quoted text occur in the retrieved chunk?

03Support

Does the passage support the claim—not merely mention the topic?

04Refuse

If no passage answers, did the system preserve “not found”?

The lab automates the first two checks. A human still judges whether the evidence truly supports the meaning of the answer.
