The shared method

Evaluate the system at three layers.

01

Interface

Did it return the required fields, citations, or tool call in a machine-checkable shape?

02

Evidence

Can each consequential claim be traced to an input passage, retrieved file, transcript, or tool result?

03

Decision

Is the conclusion calibrated to the design—and is a named human responsible for the next action?

The aim is not “AI everywhere.” It is useful assistance with visible evidence and bounded authority.
