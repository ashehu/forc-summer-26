The case-study sequence

One capability, one failure mode, one verification habit.

01
30 minutesinformation extraction

Make messy research records comparable.

Turn four differently written study notes into a strict schema. First watch brittle rules fail; then test schema-constrained model output against a gold set.

Failure to find: a plausible value that is not actually stated.
Check to keep: field accuracy + exact evidence quote.

03
45 minutestool-using agent

Give a model analysis tools, not a blank check.

A model may choose among five local functions. The data hide a Simpson's-paradox reversal, so students must inspect the trace—not merely the prose answer.

Failure to find: a misleading aggregate comparison.
Check to keep: tool trace + stratified result + causal caution.

The shared method

Evaluate the system at three layers.

01

Interface

Did it return the required fields, citations, or tool call in a machine-checkable shape?

02

Evidence

Can each consequential claim be traced to an input passage, retrieved file, transcript, or tool result?

03

Decision

Is the conclusion calibrated to the design—and is a named human responsible for the next action?

The aim is not “AI everywhere.” It is useful assistance with visible evidence and bounded authority.
